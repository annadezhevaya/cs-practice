#Воркшоп
git diff - сравнивает две версии и показывает чем они отличаются.
git show - показывает один коммит: кто сделал, когда, и что в нём изменилось.
git log - показывает список всех коммитов, у каждого короткое сообщение.
git log -S - ищет в каком коммите находится эта строка.
git blame - показывает для каждой строки файла, в каком коммите она появилась.
#git restore и git restore --source
git restore - возвращает файл к состоянию последнего коммита. Мои несохраненные правки при этом пропадают.
git restore --source=HEAD~2 - возвращает файл к состоянию из коммита двух шаговой давности, то есть к старой версии. Правки, которые я сделала после этого, тоже заменяются, а текущие несохраненные изменения были бы потеряны.
#git reset --hard и git revert
git revert HEAD не стирает ошибочный коммит. Он создаёт новый коммит, который отменяет изменения старого. В истории видно и ошибку, и её отмену.
git reset --hard стирает коммиты и правки, как будто их никогда не было. История переписывается.
В опубликованной истории revert безопаснее. Если стереть коммит через reset, у других людей, которые скачали мои коммиты, история перестанет совпадать с моей. А revert просто добавляет новый коммит, ничего не ломая.
