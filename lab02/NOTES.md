#Рабочая папка, индекс и коммит
Рабочая папка - это папка на компьютре, где лежат файлы.Git следит за изменениями в этой папке.
Индекс - это промежуточное место с файлами, которые я хочу сохранить в коммит.
Коммит - сохранение изменений в истории Git.
#Различие  Git и GitHub
Git - это программа для контроля версий, которая отслеживает изменения в файлах и помогает нескольким людям работать над одним проектом.
GitHub - это веб-сервис для хранения репозиториев Git в интернете.
#Использованные команды
git status - показывает текущее состояние репозитория: какие файлы изменены, какие добавлены в индекс, какие еще не отслеживаются.
git diff - показывает разницу между рабочей папкой и индексом.
git diff --staged - показывает разницу между индексом и коммитом.
#Ветки
Ветка - это отдельная линия разработки. Она позволяет работать над изменениями, не затрагивая основную версию проекта.
При новом коммите ветка сдвигается вперед - она указывает на последний коммит в этой линии.
Слияние - это объединение изменений из одной ветки в другую.
